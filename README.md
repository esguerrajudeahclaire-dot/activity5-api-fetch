
# Activity 5 - REST API Fetch

## Description
A simple React Native application that fetches
and displays data from a public REST API.

## API Used
JSONPlaceholder

https://jsonplaceholder.typicode.com/posts

## Features
- Fetch API data using fetch()
- Uses async and await
- Uses useEffect
- Uses useState
- Loading indicator
- Error handling
- Displays five API posts

## Technologies
- React Native
- JavaScript
- Expo
- JSONPlaceholder API
